# STEEL//RIVALS — 像素机甲对决

一个纯前端、零外部依赖的复古像素风 1v1 机甲对战小游戏。玩家驾驶「苍隼 AZURE-01」，在合成波风格的废弃空港迎战重装机甲「赤鬼 CRIMSON-07」。

所有角色、场景、特效与音效均在运行时程序化生成：没有图片、字体或音频文件。

## 运行方式

```bash
cd /workspace
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000
```

也可以直接双击 `index.html`（不依赖模块加载或网络资源）。推荐 Chrome / Edge。

## Windows 单文件版（EXE）

双击 `STEEL-RIVALS-Windows-x64.exe` 即可开玩：

- 无需安装，游戏文件全部内嵌在 EXE 中，断网也能运行。
- 自动使用 Edge / Chrome 的应用窗口打开（无地址栏）；关闭窗口后程序自动退出。
- 未做代码签名，首次运行若出现 SmartScreen 提示，选择「更多信息 → 仍要运行」。
- 若手柄没有反应，请把控制器切换到 **XInput / PC 模式**（Xbox、PXN 等常见手柄均适用）。

## 玩法设计

### 对局规则
- 单回合 **75 秒**，双方初始 **100 HP**。
- 击破对方机体即 **K.O.** 获胜；时间耗尽则比较剩余血量，高者胜，相同为 **DRAW**。
- 结算界面显示比分、造成伤害、有效命中与成功格挡次数，可直接再战。

### 战斗资源
- **生命值 HP**：归零即败。
- **护盾能量 SHD**：格挡时持续消耗（22/s），受击时额外消耗；护盾为 0 会 **GUARD BREAK**，陷入约 0.9 秒硬直。
- 非格挡状态且短暂延迟后，护盾会以 16/s 自动回复。

### 攻防循环
- **脉冲炮**：直线弹道，跳跃可以躲避；适合中远距离压制。
- **等离子斩**：近距离高伤害，前摇短、后摇长，风险与收益并存。
- **格挡**：只抵挡正面攻击，大幅减伤（约 88%），但会快速消耗护盾；破盾会暴露巨大破绽。
- **击退与硬直**：受击会短暂硬直并被推开，近战命中硬直更长；连续压制可以打乱对手节奏。
- **AI 行为**：中距离游走射击、近距离斩击、侦测弹道后概率格挡或跳跃，并根据距离重新选择站位。

### 数值表

| 属性 | 苍隼（玩家） | 赤鬼（AI） |
| --- | --- | --- |
| 生命 | 100 | 100 |
| 移动速度 | 84 | 65 |
| 跳跃初速 | 258 | 238 |
| 脉冲炮伤害 | 7 | 7 |
| 脉冲炮冷却 | 0.37 s | 0.90 s |
| 等离子斩伤害 | 16 | 16 |
| 等离子斩冷却 | 0.96 s | 1.26 s |
| 弹速 | 292 | 258 |

玩家射速更快、机动性更高；AI 单发更重、更耐打，但攻击间隔更长。

## 核心代码结构

```
/workspace
├── index.html   # 页面结构：HUD、开始/暂停/结算覆盖层、触屏按键、Canvas
├── style.css    # 复古街机外观、扫描线、CRT 暗角、响应式与像素化渲染
└── game.js      # 全部游戏逻辑（单文件 IIFE，无构建步骤）
```

`game.js` 按 7 个区块组织：

1. **常量 / DOM / 音频**：画布 480×270、重力、回合时长、调色板、角色档案；WebAudio 合成音效与主音量。
2. **工具 / 角色工厂 / 状态**：`createFighter()` 生成双方机体，`resetFighter()` 重置回合，`game` 保存回合、比分、屏幕震动等状态。
3. **输入 / 流程**：键盘与虚拟按键、开始、暂停、静音、结算界面切换。
4. **程序化背景**：离屏 Canvas 预渲染合成波夕阳、城市剪影、反应堆环与平台；动态层绘制光柱、无人机、塔灯、雾与漂浮粒子。
5. **战斗更新**：
   - `updateBattle()`：主战斗循环，推进计时、AI、物理、弹道、特效与胜负。
   - `controlPlayer()` / `updateAI()`：玩家输入与敌方决策。
   - `updateFighter()`：移动、重力、跳跃、动作状态机、护盾消耗与回复。
   - `fireProjectile()` / `doMeleeHit()` / `applyDamage()`：攻击生成、命中判定、格挡/破盾/击退。
   - `triggerKO()` / `triggerTimeUp()` / `endRound()`：胜负判定与结算数据。
6. **机甲与特效绘制**：
   - `mechShape()`：用 `fillRect` 像素块拼装机甲，包含头部、躯干、肩甲、炮管、腿部、天线/犄角、护盾弧与近战光刃。
   - `drawMech()`：影子、朝向翻转、受击闪白、KO 倒地旋转。
   - `drawProjectiles()` / `drawParticles()` / `drawPopups()`：弹道、火花、烟雾、伤害数字。
7. **HUD / 主循环**：血条、护盾条、倒计时、屏幕震动与闪白，`requestAnimationFrame` 驱动。

### 动画状态
机甲绘制根据状态切换姿态：`idle` 呼吸浮动、`walk` 双腿摆动、`jump` 收腿与推进焰、`shoot` 炮身后坐、`melee` 光刃挥砍、`guard` 护盾弧、`hurt` 抖动闪白、`ko` 倒地、`victory` 举炮庆祝。

## 基础素材方案

项目不包含任何外部素材，素材由“像素块 + 调色板 + 程序动画”构成。

### 1. 角色精灵
- 以脚底为原点、本地坐标绘制，整体约 30×56 像素。
- 部件拆分：头、面罩、天线/犄角、胸甲、能量核心、肩甲、后臂、炮管、双腿、脚掌。
- 双方共用部件结构，通过调色板和轮廓细节区分：
  - 苍隼：青蓝色系、单天线、轻型肩甲、细炮管。
  - 赤鬼：红橙色系、双犄角、尖刺肩甲、厚重炮管。
- 受击时以同一形状再绘制一遍纯白调色板，形成街机式闪白。

### 2. 调色板
- 每台机甲 10 色：`outline / dark / mid / light / pale / metal / accent / core / flame / hostile`。
- 背景使用深蓝紫、洋红、橙黄三组渐变，配合霓虹青与警示红作为界面强调色。

### 3. 场景层
- 静态层：渐变天空、条纹夕阳、远近两层城市剪影、巨型反应堆环、地面平台与灯带。
- 动态层：光柱透明度呼吸、无人机巡航、塔灯闪烁、雾带漂移、漂浮尘埃。
- 屏幕表现：扫描线、暗角、像素化缩放、受击闪白与屏幕震动。

### 4. 特效
- 由矩形粒子构成：炮口火花、弹道拖尾、命中火花、格挡星火、落地烟尘、低血量黑烟、KO 爆炸。
- 伤害数字与 `BLOCK` / `GUARD BREAK` / `K.O.` 文本使用 Canvas 等宽字体绘制。

### 5. 音效
- 全部由 WebAudio 实时合成：
  - 振荡器：方波/锯齿波/三角波，配合频率滑音。
  - 噪声：带通滤波白噪声，用于命中、格挡、落地与爆炸。
- 音效事件：`shoot / melee / hit / heavyHit / block / guardBreak / jump / land / ko / win / lose / ui`。

## 设计取舍
- 固定 480×270 内部分辨率，CSS 放大并启用 `image-rendering: pixelated`，保证像素边缘清晰。
- 单文件 IIFE 便于直接运行与阅读，不引入框架、构建工具或资源加载。
- 以“短回合 + 资源管理 + 攻防读招”为核心，操作简单但保留格挡破盾的博弈空间。
